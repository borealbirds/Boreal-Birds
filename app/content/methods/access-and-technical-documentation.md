Public 2020 prediction rasters, model summaries, and metadata can be explored or accessed through the **Use Models** tab. Predictions for 1990 through 2015 at five-year intervals are available upon request through the [BAM contact page](https://borealbirds.ca/contact/).

The [LandbirdModelsV5 repository](https://github.com/borealbirds/LandbirdModelsV5) contains the modelling and spatial-processing workflow. The repository remains under development; a release-specific Version 5.0 code archive will be linked when the dataset release is finalized.

See the **Citation** tab for the Version 5.0 dataset citation and the publication describing the generalized modelling framework.
